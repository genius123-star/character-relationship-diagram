# 人物关系图谱实施计划

状态：执行中（2026-08-13）

## Approach

采用纵向切片：每个阶段都交付可运行、可验证的用户能力，而不是先堆满基础设施。先实现数据模型、持久化和最小图谱闭环，再逐步加入高级交互；每阶段通过测试后才进入下一阶段。

## Scope

- In：PRD v1.0 的 FR-01 至 FR-12、桌面浏览器界面、IndexedDB 本地保存、JSON 备份、300 人/1,000 关系性能验证。
- Out：服务端、账号同步、AI 抽取、真正防剧透、科研与社交模式、亲属称谓、插件、Excel/CSV、移动端专项适配。

## 旅程图产品决策（2026-09-16）

旅程图前端冻结：不再提供创建、打开或编辑入口，也不启动母图—子图改造。保留既有 `journey` 数据、校验、导入导出和实现，以保证已保存项目可恢复；冻结不等同于删除。当前资源继续投入弹窗化与划词解析（W1–W5）。仅当移动路径是目标场景的主线，且章节与事件地点可自动生成大部分行程数据时，再以“叙事线”重新立项。
