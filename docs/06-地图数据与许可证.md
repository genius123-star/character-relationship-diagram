# 地理图底图数据与许可证记录

更新时间：2026-08-18  
对应：PRD 13.4 “地图内核及底图数据的许可证、署名、缓存范围和导出规则有书面记录”

## 底图数据源

| 项 | 值 |
|---|---|
| 服务 | OpenFreeMap（`https://tiles.openfreemap.org/planet`，TileJSON） |
| 瓦片端点 | `https://tiles.openfreemap.org/planet/20260802_080001_pt/{z}/{x}/{y}.pbf` |
| 数据来源 | OpenStreetMap 贡献者（经 OpenMapTiles schema 处理） |
| 署名要求 | 地图可见署名“© OpenFreeMap”，已由 MapLibre attribution control 显示 |
| API Key | 无需 |
| 格式 | MVT 矢量瓦片（pbf） |
| 覆盖 | 全球，maxzoom 14 |

> 说明：该端点为快照式路径（含日期戳）。若端点失效，请更新 `GeographyCanvas.tsx` 中 `buildBasemapStyle` 的 `tiles` 数组为 OpenFreeMap 最新 `https://tiles.openfreemap.org/planet` 返回的瓦片 URL。

## 离线/断网回退

- 内置世界轮廓 `public/map-data/world-outline.geojson`（约 98 KB，由 world-atlas `land-110m` 简化生成），作为瓦片未加载/断网时的低缩放占位。
- 用户人物、关系、地点确认与视图配置始终本地保存，不进入远程瓦片服务。

## 地点解析服务

| 项 | 值 |
|---|---|
| 服务 | 镜像地球的 Nominatim 镜像（`https://api.mirror-earth.com/nominatim/search`） |
| 数据来源 | OpenStreetMap 贡献者，经 Nominatim 反向地理编码 |
| 许可 | ODbL 1.0（响应 `licence` 字段：`Data © OpenStreetMap contributors, ODbL 1.0`） |
| API Key | 无需 |
| CORS | `Access-Control-Allow-Origin: *`，浏览器直连可用（国内网络实测可达） |
| 限频 | 1 req/s（`geocoding.ts` 模块级节流） |

> 说明：`src/features/geography/geocoding.ts` 中 `GEOCODING_ENDPOINT` 为解析端点常量，默认镜像地球；官方 `nominatim.openstreetmap.org` 保留在注释中作为备选（国内网络通常不可达）。若镜像失效，可切换回官方或接入高德/腾讯 Web 服务（需申请 Key）。

> 官方文档：https://open.mirror-earth.com/docs/get-started/8-geo（免费、无需 Key；建议每秒不超过 1 个请求；免费服务无服务级别保证；429 表示请求频率超限）。数据基于 OpenStreetMap，遵循 ODbL 1.0。

## 自托管地图字形

- `public/glyphs/Noto Sans Regular/` 内置 MapLibre 字形（约 1.6 MB，21 个 range 文件，覆盖拉丁/希腊/西里尔/通用标点/CJK 标点）；`buildBasemapStyle` 的 `glyphs` 指向 `/glyphs/{fontstack}/{range}.pbf`，不再依赖 demotiles.maplibre.org 公共字体服务。
- 中文（CJK）由 MapLibre 默认 `localIdeographFontFamily: "sans-serif"` 走浏览器本地字体渲染，不请求字形服务。
- 未内置的稀有字符 range 由 MapLibre 本地渲染兜底（控制台提示 `Unable to load glyph range … Rendering codepoint … locally instead`，不影响显示）。
- 刷新字形：`node scripts/fetch-glyphs.mjs`（从 demotiles 下载，需联网）。

## 缓存范围

- 浏览器端 MapLibre 瓦片缓存仅缓存 OpenFreeMap 公开瓦片数据，不缓存或上传任何用户人物/关系事实。
- 地理解析仅缓存唯一结果的坐标与展示名到 localStorage（键前缀 `character-graph:geocoding:`），不缓存用户人物/关系事实；歧义候选不写缓存。
- 瓦片按视口（HTTP Range）请求，仅下载当前视图所需内容；断开网络后自动回退到内置轮廓。

## 导出规则（本阶段）

- 地理图的 PNG/JPG/PDF 完整导出不在本阶段范围；PRD FR-12 的图像导出仅覆盖人物关系图（Cytoscape）。
- 若后续加入地理图导出，底图瓦片仅作为渲染背景，导出的图像须包含 OpenFreeMap/OSM 署名（含解析结果来自 OSM 的署名要求）。
